# Flight Booking System

A modern Windows Forms application for searching and booking flights, built with .NET 8.

## Features

- Search for flights by origin, destination, and date
- View flight details and images
- Book flights and manage your bookings
- User-friendly interface

## Getting Started

1. Clone the repository.
2. Open the solution in Visual Studio 2022.
3. Build and run the project.

## Requirements

- .NET 8 SDK
- Visual Studio 2022
